# 📊 Analytix Forum Website

> The official web platform for the Analytix forum, built for speed, interaction, and seamless content management. 

Hosted entirely on **GitHub Pages**, this website serves as the digital hub for our student community, providing workshop resources, event updates, and information about our team.

---

## ✨ Key Features

*   **Role-Based Access (Editor Mode):** Integrated with **Decap CMS**, allowing verified "Members" to access an `/admin` dashboard to edit site content, manage events, and upload files without touching the codebase.
*   **Interactive UI & Animations:** Fully styled with **Tailwind CSS** featuring neon shadows and looping video backgrounds, enhanced by **AOS (Animate On Scroll)** for professional, sequential entrance animations.
*   **Dedicated Resource Library:** A dedicated section offering direct PDF downloads for our core workshops:
    *   *SQL Fundamentals* (Query optimization & joins)
    *   *Advanced Excel* (Using the CHOOSE function & datasets)
    *   *SPSS Analysis* (Statistical testing guides)
    *   *Advanced Statistics* (Regression & Forecasting)

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3, JavaScript
*   **Styling:** Tailwind CSS
*   **Animations:** AOS (Animate On Scroll) v2.3.1
*   **Content Management (CMS):** Decap CMS (v3.1.2)
*   **Hosting & Deployment:** GitHub Pages
